# 🚀 Crowdfunding Campaign Performance Predictor

### AI-Powered Machine Learning Application for Crowdfunding Success Prediction

## 📌 Project Overview

The **Crowdfunding Campaign Performance Predictor** is an AI-powered Machine Learning project designed to predict the potential success of crowdfunding campaigns using historical campaign data.

The application analyzes important pre-launch campaign characteristics such as funding goal, category, subcategory, country, campaign duration, title length and launch timing to generate a **Success Probability**.

The project is deployed as an interactive **Streamlit web application**, allowing users to enter campaign details and instantly receive a prediction.

---

## 🎯 Project Objective

The primary objective is to help entrepreneurs and campaign creators understand the potential performance of a crowdfunding campaign before launching it.

The system provides:

- 🔮 Success probability prediction
- 📊 Historical campaign analytics
- 🤖 Machine Learning model performance
- ⚠️ Risk-level classification
- 💡 Campaign recommendations
- 📈 Interactive visualizations

---

## 🧠 Machine Learning Approach

The project uses **Logistic Regression** as the prediction model.
